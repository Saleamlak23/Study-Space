# StudyLens

StudyLens is a local-first study workspace for desktop Chrome and Edge. It lets a student select a local folder, browse study files, preview documents inline, and maintain a rich `note.html` file in the same folder.

## Scripts

- `npm run dev` starts the Vite development server.
- `npm run build` type-checks and builds the app.
- `npm run preview` serves the production build locally.

## Browser Support

Full workspace mode requires the File System Access API, currently supported in Chromium browsers. Other browsers receive a read-only drag-and-drop fallback.
